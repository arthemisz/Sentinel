# Code of Conduct

## Our pledge

We want Sentinel to be a welcoming, useful, and respectful project for everyone. Contributors are expected to participate in good faith and to help keep discussions focused on the work rather than on people.

## Expected behavior

- Be respectful and constructive in issues, reviews, and discussions.
- Assume good intent while asking for clarification when something is unclear.
- Give useful feedback about code, documentation, and ideas.
- Accept a change of direction when maintainers make a decision.
- Protect private information and report security issues responsibly.

## Unacceptable behavior

Harassment, discrimination, personal attacks, doxxing, unwanted sexual attention, threats, and deliberate disruption are not acceptable. This also includes publishing private information without permission or attempting to bypass project security controls.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or restrict participation when behavior conflicts with this code. Serious or repeated issues may result in a permanent ban from project spaces.

Report conduct concerns privately through the security reporting process in [SECURITY.md](SECURITY.md). Please include enough context for the maintainers to understand what happened and how to follow up.

## Scope

This code applies in project repositories, issue trackers, pull requests, chats, and other spaces when someone is representing Sentinel or materially affecting the project community.

This code of conduct is adapted from the Contributor Covenant, version 2.1.
